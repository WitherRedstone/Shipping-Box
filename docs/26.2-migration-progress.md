## 关键 MC 26.2 API 变更

### Block/Item 注册

```java
// 1.21.1(旧)
BLOCK.register("name", () -> new Block(Properties));
ITEM.register("name", () -> new Item(Properties));

// 26.2(新) — Properties 构造时需注入 id,通过 Function<Identifier, T> 实现
BLOCK.registerBlock("name", 
    props -> new Block(props.id(requiredId).otherProps...));
ITEM.registerItem("name", 
    props -> new Item(props.id(requiredId).otherProps...));
```

### DataFix types

BlockBehaviour/Item Properties 的 id 在构造时已知(通过 `Properties.of().id(id)` 的链式调用),所有依赖 id 的 getter(effectiveModel, effectiveDrops, effectiveDescriptionId)可以在构造阶段安全访问。

### SavedData 重构

```java
// 1.21(旧)
SavedData.Factory<T> factory = new SavedData.Factory<>(constructor, loader);
save(CompoundTag tag, HolderLookup.Provider provider);  // 自定义
static T loadFromNBT(CompoundTag tag, HolderLookup.Provider provider);

// 26.2(新) — 通过 Codec 驱动序列化
SavedDataType<T> TYPE = new SavedDataType<>(id, constructor, codec, dataFixType);
// 不再需要 override save/load
```

### Value-Based NBT IO

```java
// 1.21
tag.getLongOr("key");  // 不存在
tag.getCompound("key");  // 返回 CompoundTag

// 26.2
tag.getLongOr("key", -1L);  // 需要默认值
tag.getCompound("key");  // 返回 Optional<CompoundTag>
tag.keySet();  // 替代 getAllKeys()
tag.child("name");  // 返回 Optional<ValueOutput>
```

### Transfer API

- `IItemHandler` / `CapabilityItemHandler` / `ItemStackHandler` → 删除
- `ResourceHandler<ItemResource>` / `VanillaContainerWrapper.of(container)` → 新方案
- `Capabilities.ItemHandler.BLOCK` → `Capabilities.Item.BLOCK`
